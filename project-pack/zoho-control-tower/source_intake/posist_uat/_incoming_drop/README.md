# Drop POSist UAT Files Here

Put screenshots, API documentation screenshots, API docs, exported reports, and sample responses in this folder.

Subfolders are fine. Codex will scan recursively.

Run from the project root:

```powershell
scripts\prepare_posist_screenshot_intake.bat
```

Generated Codex analysis files will appear under `source_intake/posist_uat/batches/YYYY-MM-DD/`.
