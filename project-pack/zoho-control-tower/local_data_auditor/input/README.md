# Local CSV Drop

Place Restroworks CSV exports here, or pass another folder to
`run_full_pipeline.bat`.

Use:

```text
<canonical_report_prefix>__<from_YYYY-MM-DD>__<to_YYYY-MM-DD>__<scope>.csv
<canonical_report_prefix>__snapshot__<YYYY-MM-DD>__<scope>.csv
```

Keep months separate, preserve exported headers, and do not place screenshots or
Excel workbooks here. This folder is ignored by Git except for this guide.
